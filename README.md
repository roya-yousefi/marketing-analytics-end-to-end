# 📊 Marketing Funnel Analysis Project

## 📌 Overview

This project analyzes a full marketing funnel from website traffic to account creation, customer conversion, and product usage.

The goal is to evaluate marketing performance across different channels, countries, and subscription types, and extract actionable business insights using SQL, Python, and Power BI.

---

## 🎯 Objective

- Analyze user behavior across the marketing funnel  
- Measure conversion rates between funnel stages  
- Evaluate performance by channel, country, and subscription type  
- Identify opportunities to improve marketing efficiency  

---

## 📁 Dataset Structure

- Website Traffic → user visits (country, city, channel)  
- Account Creations → registered users  
- Customers → users who completed the first shipment  
- Parcels Shipped → usage and engagement data  

---

## 🛠️ Tools

- Python → data cleaning, transformation & analysis  
- SQL → data preparation, joins & querying  
- Power BI → dashboard design & visualization  

---

## 🔄 Analysis Performed

- Funnel conversion analysis (Traffic → Customer)  
- Channel performance comparison  
- Country-level analysis  
- Subscription type behavior  
- Time-based trend analysis  

---

## 🔑 Key Insights

**1. Channel Quality**  
Some channels generate high traffic but low-quality conversions.  

**2. Funnel Drop-off**  
A major drop-off occurs between website traffic and account creation.  

**3. Market Opportunity**  
Certain countries show strong conversion potential despite lower traffic.  

**4. Subscription Impact**  
Subscription type strongly influences customer value and engagement.  

**5. Trend Analysis**  
Traffic and account creation show clear time-based patterns.
